# Contributing

## Contributions

Open a focused issue or pull request that explains the maintainer or contributor problem being solved. Keep changes offline, dependency-light, and easy to audit.

## Tests

Create a virtual environment, install the test extra, and run `pytest -q` plus `python -m compileall -q src tests` before opening a pull request.

## Pull requests

Describe the user-facing behavior, tests run, documentation updates, security impact, and honest limitations. Do not include secrets, private repository contents, or claims that cannot be reproduced from the checked-in examples.
