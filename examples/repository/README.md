# Example repository

This fixture demonstrates a small repository with explicit contribution guidance, a security policy, a license, and a pull-request checklist. It is intentionally local and contains no application code or credentials.

## Quick start

Run `contrib-lint examples/repository --fail-on warning` from the parent project. A complete fixture should produce no warning-level findings.

## Scope

The example exists only for tests and documentation. It is not a production application and should not be used as a security boundary.
